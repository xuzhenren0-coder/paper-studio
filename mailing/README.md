# 晨读模块

晨读是独立部署的辅助学习入口。Windows 阅读器无需配置晨读就能使用。公开下载包不含任何邮箱、模型或云端凭据，也不接入维护者的私人订阅名单。

## 流程

按用户关键词检索近期车辆工程及控制论文，核对 DOI、出版来源、日期与可用节选许可；从合格候选和近一年未读储备中选文，生成中文导读、英文节选与译文、3 个术语和 1 个学习问题。AI 译文与判断仍需对照原文。没有合格内容时跳过。

每位订阅者可选择北京时间全天每 5 分钟一档、每天／周一至周五／自选星期、入门／进阶讲解、精简／标准篇幅。每人每天最多一封，修改到已过时刻不补发。准备不足最多延后 30 分钟；发送状态不确定时不自动重发。

## 代码与配置

- core、papers、personal、preferences：内容门槛、选文与个性化。
- subscriptions、member_bridge、member_mail：邀请、邮箱验证、免密码管理、偏好及退订。
- service、fc_handler、cloud_store：云端任务、定时入口和持久防重记录。
- smtp、aliyun：发信适配；实际可用通道取决于部署者自己的账号、认证与供应商限制。
- secret_config：本机加密配置支持，不包含凭据。

完整云端模块位于 Release 源码包和 Git 仓库；Windows 包只保留本地用户管理与预览所需的子集。订阅网页见 subscription-web/README.md。部署者需自备私有持久存储、定时执行服务、模型接口和发信账号，配置订阅桥接地址与密钥、公开 HTTPS 管理入口。不得将这些私有值写入源码。修改公开源码不会自动更新任何已运行的云服务。

## 验证与限制

本地可运行 python tools/preview_morning_mail.py，输出原创示例，不发真实邮件。上线前应在自己的环境完成来源核验、邮箱验证、退订、时区、防重及实际收件测试。邮件服务器接受请求不等于最终送达；不得把 unknown 状态当成失败直接重发。小范围试用不能替代正式规模下的投递与学习效果验证。
