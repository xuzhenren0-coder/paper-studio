# 晨读订阅源码

此目录提供邮箱免密码登录、受邀确认、研究关键词、发送时间和星期、难度与篇幅、暂停恢复及退订页面。订阅数据使用 D1，邮件任务由部署者自己的晨读服务执行。

## 开发和构建

使用 Node.js 22.13 或更高版本及 pnpm，在本目录安装依赖后运行 pnpm dev 或 pnpm build。数据库结构见 drizzle 和 db 目录，接口位于 app/api。当前包的阅读器可独立启动。

## 配置

部署前需设置 D1 绑定 DB、至少 32 字符的 MEMBER_BRIDGE_SECRET 和 HTTPS 的 MEMBER_PUBLIC_ORIGIN。晨读后台需配置自己的模型与发信服务，并设置相同的桥接密钥。密钥通过部署平台的私有环境变量配置。

此源码包中的前端改动需要部署后才能在自己的订阅站点生效。公开源码使用项目根目录许可证，依赖保留各自许可证。
